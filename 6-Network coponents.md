NETWORK COMPONENTS – COMPLETE NOTES
1. Introduction to Network Components
A computer network is a group of computers and other devices connected together to share data, information, resources, and services.

Network components are the physical devices and software required to establish, operate, and maintain a computer network.

Definition:
Network components are the hardware and software elements that help computers communicate and exchange information with each other.
2. Types of Network Components
Network components are mainly divided into two categories:
1. Hardware Components
2. Software Components
3. Hardware Components
Hardware components are the physical devices used to connect computers and establish communication in a network.
1. Network Interface Card (NIC)
A Network Interface Card (NIC) is a hardware component that connects a computer to a network.

Functions:
- Connects computers to a network.
- Sends and receives data.
- Provides a unique MAC address.
- Supports wired and wireless connections.
2. Hub
A hub is a networking device used to connect multiple computers in a network.

It receives data from one computer and sends it to all connected devices.

Functions:
- Connects multiple computers.
- Transfers data between devices.
- Acts as a central connection point.
Disadvantage: It sends data to all connected devices, which can create unnecessary network traffic.
3. Switch
A switch is a networking device used to connect multiple computers and devices within a LAN.

It forwards data to the intended device using its MAC address.

Functions:
- Connects multiple devices.
- Reduces unnecessary network traffic.
- Improves network performance.
- Transfers data efficiently.
4. Router
A router is a networking device that connects two or more different networks.

It forwards data packets between networks using IP addresses.

Functions:
- Connects a LAN to the internet.
- Transfers data between networks.
- Selects the best path for data.
- Helps manage network traffic.
5. Modem
A modem stands for Modulator-Demodulator.

It is a device that converts signals to enable communication between a computer or network and an internet service provider.

Functions:
- Helps establish an internet connection.
- Converts signals for transmission.
- Connects a network to an internet service provider.
6. Repeater
A repeater is a networking device that receives weak signals, regenerates them, and retransmits them.

Functions:
- Extends network coverage.
- Regenerates weak signals.
- Helps data travel longer distances.
7. Bridge
A bridge is a networking device used to connect two or more LAN segments.

It filters and forwards data based on MAC addresses.

Functions:
- Connects network segments.
- Reduces unnecessary traffic.
- Improves network efficiency.
8. Gateway
A gateway is a networking device that connects two different networks that may use different communication protocols.

Functions:
- Connects different types of networks.
- Translates communication protocols.
- Allows communication between different networks.
9. Transmission Media
Transmission media refers to the path through which data travels from one device to another.

It is divided into two types:

A. Guided Media (Wired)

Data travels through physical cables.

Examples:
1. Twisted Pair Cable
2. Coaxial Cable
3. Optical Fibre Cable
B. Unguided Media (Wireless)

Data travels through air using electromagnetic waves.

Examples:
1. Radio Waves
2. Microwaves
3. Infrared Waves
4. Satellite Communication
10. Server
A server is a computer or system that provides services, resources, and information to other computers called clients.

Functions:
- Stores files and data.
- Manages network resources.
- Provides services to clients.
- Controls access to network resources.
11. Client
A client is a computer or device that requests services and resources from a server.

Functions:
- Requests data from servers.
- Accesses shared resources.
- Uses network services.
- Communicates with other devices.
4. Software Components of a Network
Software components are programs and applications that help manage and operate a computer network.
1. Network Operating System (NOS)
A Network Operating System is software that manages network resources and allows computers to communicate with each other.

Examples:
- Windows Server
- Linux
- UNIX
2. Network Protocols
Network protocols are rules and standards that control communication between devices in a network.

Examples:
- TCP/IP
- HTTP
- FTP
- SMTP
- DNS
3. Network Security Software
Network security software protects the network from unauthorized access, viruses, malware, and cyber threats.

Examples:
- Antivirus software
- Firewall software
- Network monitoring tools
5. Difference Between Hub and Switch
Hub	Switch
Works at the Physical Layer.	Works at the Data Link Layer.
Sends data to all connected devices.	Sends data to the intended device.
Less efficient.	More efficient.
Does not use MAC addresses to forward data.	Uses MAC addresses to forward data.
Creates more unnecessary traffic.	Reduces unnecessary traffic.


6. Difference Between Router and Switch
Router	Switch
Connects different networks.	Connects devices within a network.
Uses IP addresses.	Commonly uses MAC addresses.
Works mainly at the Network Layer.	A traditional switch works at the Data Link Layer.
Selects routes for data packets.	Forwards frames within a LAN.
Connects LANs to the internet.	Connects computers within a LAN.


7. Importance of Network Components
Network components are important for the following reasons:
1. They help establish communication between computers.
2. They allow sharing of files and information.
3. They provide internet connectivity.
4. They improve data transmission.
5. They help manage network resources.
6. They provide network security.
7. They make communication faster and easier.
8. Applications of Network Components
Network components are commonly used in:
1. Schools and colleges.
2. Banks and financial institutions.
3. Hospitals.
4. Offices and businesses.
5. Government organizations.
6. Computer laboratories.
7. Industries.
8. Homes and educational institutions.
9. Conclusion
Network components are essential parts of a computer network. They help establish connections, transfer data, share resources, and provide communication between different devices. Hardware components such as routers, switches, hubs, modems, and network interface cards work together with software components to make networking possible.

Therefore, network components play an important role in building and maintaining an efficient, reliable, and secure computer network.
